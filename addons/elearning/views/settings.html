Shared folders

Course managers pick video files from these folders (Browse in the lesson editor); the server reads the file and streams it to learners, so learners don't need access to the share themselves.

The folder must be readable by the account the server runs as (for a Windows service, often Local System, which has no access to network shares: run the service as a domain account that can read the share, or grant the server's computer account access). Mapped drive letters (Z:\) belong to a signed-in user; use the \\server\share path instead.

No shared folders

YouTube and Google Drive videos work without any. Add a folder to play video files from your network.

Removing a folder stops the videos of lessons that use it from playing. Changing a folder's path (the share moved) keeps them playing from the new path, as long as the files are in the same places inside it.
